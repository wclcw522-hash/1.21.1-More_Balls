### L3 打通过程中额外确认的事实（都是编译报错逼出来的，不是猜的）

| 现象 | 1.21.1 的真实情况 |
|---|---|
| `Item.use` 覆盖报「方法不会覆盖」 | 1.21.1 返回 **`InteractionResultHolder<ItemStack>`**（26.2 才改成 `InteractionResult`） |
| `Bee` 子类的 `addAdditionalSaveData(CompoundTag)` 覆盖报错 | 1.21.1 的 `Bee` 把它声明成 **`public`**，覆盖写 `protected` 会因「可见性收窄」失败 |
| `TagKey<EntityType<?>>` 报「类型 EntityType 不带有参数」 | **`ModTags` 内部有个同名嵌套类 `EntityType` 遮蔽了原版类** → 已改名为 `Entities` |
| `AttachmentType.Builder.serialize(MapCodec)` 找不到 | 1.21.1 只收 **`Codec<T>`**，`xxx.fieldOf("name")` 要退回 `xxx` |
| `CustomRecipe` 子类是抽象类 | 1.21.1 必须自己实现 **`canCraftInDimensions(int,int)`** |
| `SavedDataType` + codec 自动序列化 | 1.21.1 只有 **`SavedData.Factory(Supplier, BiFunction)`**，`save(CompoundTag, Provider)` 要手写 |
| `EntityType.create(Level, MobSpawnType)` | 1.21.1 只有 **`create(Level)`** |
| `ItemCooldowns.addCooldown(ItemStack, int)` | 1.21.1 收 **`Item`** |
| `DustParticleOptions(int color, float)` | 1.21.1 收 **`Vector3f`**（RGB int 是 26.2 才有的重载） |
| `Entity.spawnAtLocation(ServerLevel, ItemStack, float)` | 1.21.1 是 **`spawnAtLocation(ItemStack, float)`**（没有 ServerLevel 参数） |
| `Entity.snapTo(...)` | 1.21.1 叫 **`moveTo(...)`** |
| `Entity.entityTags()` | 1.21.1 叫 **`getTags()`** |
| `ServerPlayer.forceSetRotation(...)` | 1.21.1 没有 → 降级为 `setYRot/setXRot/setYHeadRot` |
| `MobEffect.applyEffectTick(ServerLevel, LivingEntity, int)` | 1.21.1 是 **`(LivingEntity, int)`**（两参数） |
| `MobEffect.isInstantaneous()` | 1.21.1 拼写是 **`isInstantenous()`** |
| `ExplosionDamageCalculator.getEntityDamageAmount(Explosion, Entity, float)` | 1.21.1 是 **两参数**（无 exposure） |
| `Level.isBrightOutside()` | 1.21.1 用 **`isDay()`** |
| `Level.recipeAccess()` | 1.21.1 用 **`getRecipeManager()`** |
| `AbstractCookingRecipe.assemble(input)` | 1.21.1 要 **`assemble(input, registryAccess)`** |
| `ItemStackTemplate.fromNonEmptyStack(item)` | 1.21.1 没有该类，`ItemParticleOption` 直接收 `ItemStack` |
| `ThrownEnderpearl/Snowball(Level, LivingEntity, ItemStack)` | 1.21.1 只有 **`(Level, LivingEntity)`** |
| `Entity.interact(Player, InteractionHand, Vec3)` | 1.21.1 是 **两参数**（无 Vec3） |
| `Entity.onRemoval(RemovalReason)` | 1.21.1 是 **`onRemovedFromLevel()`**（无参） |
| `ChunkPos.x()` / `.z()` | 1.21.1 是**字段** `x` / `z` |
| `Entity.is(TagKey<EntityType<?>>)` | 1.21.1 要写 **`getType().is(tag)`** |

### L3 的语义降级（1.21.1 上没有对应物，必须记下来）

1. **`Items.COPPER_NUGGET` 不存在（铜粒是 1.21.2 才加的原版物品）**
   → 雪球-铜粒的掉落物改成 **`Items.RAW_COPPER`（粗铜）**，数量与概率不变。
   球物品本身仍叫 `snowball_copper_nugget`（那是我们自己的 id）。
2. **`Creaking`（嘎枝）不存在（1.21.4+ 生物）**
   → `BallMobAI` 里「嘎枝专属投掷节奏」整段移除，`#more_balls:ball_carriers` 的 instanceof 名单里也去掉。
3. **`Entity.getAirDrag()` 与 `isAffectedByBlocks()` 在 1.21.1 没有**
   → 对应的两个 `@Override` 移除；「回归不受方块影响」仍由 `noPhysics` 保证。
4. **`ServerPlayer.forceSetRotation` 没有纯朝向包**
   → 【震荡】的强制转向降级为服务端 `setYRot/setXRot/setYHeadRot`，靠原版同步下发。
