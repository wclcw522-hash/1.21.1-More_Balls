## 这是什么

这是《更多球》的 **1.21.1 / NeoForge** 版本线，由 **26.2 线（`more_balls` 1.1.3.34）** 移植而来。

26.2 与 1.21.1 之间隔了一整代 API：物品模型定义系统、渲染管线、配方展示体系、
DataFixer 序列化 API 全都不一样，所以这不是「改几个版本号」，而是逐层重写。
所有 API 差异与取舍都记在移植映射表里（见下）。

**支持版本：Minecraft 1.21.1 + NeoForge 21.1.255 及以上，需要 Java 21。**

---

## 内容一览

与原 26.2 线一致的核心玩法：

- **19 种碎片来源球**：木、圆石、铁、金、空心铁、紫水晶、铜、空心铜、红石、钻石、
  青金石、末影（原版末影珍珠）、潮汐、史莱姆（原版史莱姆球）、绿宝石、滴水石、蜜饯、符箓、回响
- **雪球系**：碎石、铁粒、金粒、铜粒、红石雪球、问号雪球
- **组合球**：2 个半球（上下）或 4 个四分之一球（2×2）合成，名字与词条按摆放顺序生成
- **30 条词条**：数值类 / 阈值类 / 数值类特性 / 其它类 / 组合类 / 唯一特性六类，
  切开与重组按作者定稿的规则结算
- **热量系统三层**：球自身（融化 / 引雷 / 熔融）、矿物方块（攒够烤熟破坏）、
  生物（着火、穿金属甲持续熔融物烧伤）
- **四种药水效果**：熔融物烧伤、震荡、不灭、腰缠万贯
- **五个附魔**：强弩、轻盈、极速、空气动力球、连发弩
- **七级收纳袋** + 弹药轮盘 + 自动装填（支持 Curios 饰品栏）
- **球堆**（把同种球收成一堆，耐久从低到高取出）
- **15 个成就**

## 安装

1. 装 **NeoForge 21.1.255** 或更高（1.21.1 线）
2. 把 `[更多球] More_Balls-<版本>.jar` 丢进 `.minecraft/mods/`
3. 需要 **Java 21**

**可选联动**（缺失时优雅降级，不会崩）：

- **JEI** —— 展示配方
- **AppleSkin** —— 食物提示
- **Curios** —— 收纳袋挂饰品栏

---

## 构建

需要 **JDK 21** 与 **Gradle 8.9+**：

```bash
gradle build
```

产物在 `build/libs/`。

> ⚠️ 工程路径必须是**纯 ASCII**（Gradle 的 JVM javaagent 不支持非 ASCII 路径）；
> 中文路径下构建会报 `agent library failed to init: instrument`。

---

## 兼容性

- 不硬编码任何他人 mod 的物品 id，一律走标签
- 不覆盖原版注册表内容，只加自己的标签、配方、成就
- 组合球用 `#more_balls:fragments` 系列标签匹配部件，别的 mod 往标签里加东西即可联动
- 三处 Mixin 全部只 `@Inject` + `require = 0`，原版改签名时安静跳过而不是崩游戏
- **没有 JEI / 苹果皮 / Curios 时，模组单独也必须能正常运行**

## 与 26.2 线的差异（1.21.1 上做不到 1:1 的地方）

| 项 | 26.2 | 1.21.1 这一版 |
|---|---|---|
| 铜粒雪球的掉落物 | `Items.COPPER_NUGGET` | **粗铜**（铜粒是 1.21.2 才加的原版物品），数量与概率不变 |
| 嘎枝（Creaking）持球 AI | 有独立投掷节奏 | **移除**（嘎枝是 1.21.4+ 生物） |
| 【潮涌】入水不减速 | 覆盖 `getAirDrag()` | 该钩子 1.21.1 没有，靠既有逻辑保证 |
| 回归期间不受方块影响 | 覆盖 `isAffectedByBlocks()` | 该钩子 1.21.1 没有，仍由 `noPhysics` 保证 |
| 【震荡】强制转向 | `ServerPlayer#forceSetRotation` 纯朝向包 | 降级为 `setYRot/setXRot/setYHeadRot` |
| 组合球分片图标 / 球堆图标 | 26.2 的 special 模型渲染器 | 暂用 fallback 模型（显示第 0 号分片/空壳贴图），BEWLR 版本待补 |
| 弩装填换贴图 | 物品模型定义的 `select` 按组件值 | 改为 `ItemProperties` predicate + `overrides`（19 颗球 + 组合球） |

完整的 API 对照与改动账本见 `docs/移植映射表-26.2到1.21.1.md`。
